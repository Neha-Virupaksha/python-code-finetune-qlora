QLoRA Fine-Tune: Python Data-Analysis Code Assistant

Qwen2.5-Coder-1.5B-Instruct fine-tuned with QLoRA on pandas / numpy / sklearn code generation, trained on a free-tier Colab T4 GPU. This page summarizes the evaluation results — full code and reports are in the repository.

01 — Results

Evaluated on a held-out split (never seen during training) using two independent methods.

MetricBaseFine-tunedChange
Held-out perplexity 2.166 1.731 −20.0%
Code execution success (n=40, sandboxed) 55.0% (22/40) 62.5% (25/40) +7.5 pp
— of which, syntax errors 6/40 0/40 eliminated
The fine-tune reliably improved output format — the base model wraps code in markdown fences with trailing explanatory prose and sometimes truncates mid-thought; the fine-tuned model emits clean, direct code matching the target style. This shows up as a 20% perplexity reduction and complete elimination of syntax errors in sandboxed testing. Execution success also improved, though more modestly (+7.5pp), with some individual examples flipping in each direction — a real but measured gain in runnable correctness, not a dramatic capability jump.

03 — Method

Base modelQwen2.5-Coder-1.5B-Instruct, 4-bit NF4 (QLoRA)
Dataiamtarun/python_code_instructions_18k_alpaca, filtered to ~3,300 pandas/numpy/sklearn examples
LoRA configr=32, alpha=64, targeting q/k/v/o projections
Training2 epochs, effective batch size 8, fp16 (T4 has no native bf16)
EvaluationHeld-out perplexity + sandboxed code execution (subprocess-isolated, HumanEval-style)

04 — Limitations

  • Execution success ≠ correctness. Code can run without error and still solve the task incorrectly. This eval catches crashes and syntax errors, not semantic correctness.
  • Small sample (n=40) for the execution eval — the net +7.5pp is a real but modest signal.
  • Shared dataset artifacts affect both models equally — many failures are FileNotFoundErrors on hallucinated CSV filenames from the source dataset's instructions, not something fine-tuning could fix.
  • Single training run, greedy decoding, one dataset filter. No hyperparameter sweep or multiple seeds.
See the repository for full training/eval scripts, raw reports, and the sandboxed execution harness.
